# CCP — Chittoor Cyber Pulse

**Cyber Fraud Monitoring & Intelligence Dashboard** of Chittoor District Police, Andhra Pradesh.

This GitHub Pages site shows the live dashboard. The dashboard itself is a Google Apps Script web app connected to Google Sheets; this page only displays it full-screen under a GitHub address.

- **Viewing the dashboard:** no sign-in needed.
- **New Entry / Edit Record / Reports:** the browser opens the secure Google page, Google asks for the Gmail ID, and access is checked against the authorized list.

To change the dashboard address, edit `APP_URL` in `index.html`.
